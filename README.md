## 👨‍💻 Sobre mí

Soy un desarrollador de software enfocado en **backend con Java y Spring Boot**, con experiencia en **microservicios, integración de APIs, bases de datos y soporte de aplicaciones empresariales**\.

He participado en proyectos del sector financiero, trabajando con servicios Java, diagnóstico de incidencias, pruebas y despliegues\. También desarrollo soluciones web con React y herramientas cloud\.

- 🔎 Me gusta investigar errores, analizar logs y llegar a la **causa raíz**\.
- 🔐 Me interesan la **seguridad**, JWT y el cifrado RSA/AES\.
- 🧪 Trabajo con pruebas de APIs, integración y calidad de software\.
- 🌱 Estoy explorando cómo contribuir a **Apache OpenOffice** y otros proyectos **open source**\.
